# 👮 Análise de Dados de Crimes em Londres com Google BigQuery e Power BI

Repositório dedicado à conexão, consulta, tratamento e análise exploratória de dados públicos sobre ocorrências criminais em Londres (período de 2011 a 2016), utilizando **Python**, **Google BigQuery** e visualização em **Dashboard interativo**.

## 🛠️ Tecnologias e Ferramentas Utilizadas

* **Python** (Automação de scripts e tratamento de dados)
* **Google BigQuery** (Consulta a datasets públicos na nuvem)
* **Pandas** (Estruturação e manipulação de dataframes)
* **db-dtypes** (Integração de tipos de dados entre BigQuery e Pandas)
* **Power BI** (Construção do Dashboard analítico)

---

## 📊 Dashboard do Projeto

O relatório interativo foi estruturado para apresentar uma visão macro e detalhada dos dados criminais de Londres entre 2011 e 2016, permitindo análises por ano, classe de crimes e comparação georreferenciada por região (*borough*).

* **Indicador Principal:** Mais de 4 milhões de registros de ocorrências analisados.
* **Visuais Principais:** 
  * Comparação de volume de crimes por região (*borough*).
  * Evolução temporal dos tipos de ocorrências (de 2011 a 2016).

---

## 📁 Estrutura do Projeto

* `conexao_bigquery_london_crime.py`: Script Python responsável por estabelecer a conexão com o Google BigQuery, validar o ambiente e executar consultas SQL de agregação temporal.
* `requirements.txt`: Ficheiro com as dependências necessárias para a execução do projeto.
* `.gitignore`: Configuração para ignorar ambientes virtuais e ficheiros temporários.
